# Calcit 0.13.64 upgrade / 升级 Calcit 0.13.64

## 中文

- 将 `calcit-wss` 的最低 Calcit 版本从 0.13.61 升级到 0.13.64。
- 保持 `calcit_native_ffi 0.1.3`、C-safe buffer/async ABI、typed WebSocket task capabilities 与既有连接生命周期语义不变。
- 通过真实 WebSocket connect/message/send/cancel smoke、C-safe exports、Rust tests 与静态质量门禁验证。

## English

- Raise the minimum Calcit version required by `calcit-wss` from 0.13.61 to 0.13.64.
- Keep `calcit_native_ffi 0.1.3`, the C-safe buffer/async ABI, typed WebSocket task capabilities, and existing connection lifecycle semantics unchanged.
- Verify with real WebSocket connect/message/send/cancel smoke, C-safe exports, Rust tests, and the static quality gate.
