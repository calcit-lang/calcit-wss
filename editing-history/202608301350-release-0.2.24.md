# Release 0.2.24 / 发布 0.2.24

## 中文

- 发布 `calcit-wss` 0.2.24，要求 Calcit 0.13.64。
- 保持 `calcit_native_ffi 0.1.3`、C-safe buffer/async ABI、typed WebSocket task capabilities、backpressure metrics 与连接生命周期语义不变。
- 通过 10 项 Rust 生命周期/背压测试、strict-zero quality、C-safe exports 与真实 connect/message/send/cancel smoke 验证。

## English

- Release `calcit-wss` 0.2.24 with Calcit 0.13.64 required.
- Keep `calcit_native_ffi 0.1.3`, the C-safe buffer/async ABI, typed WebSocket task capabilities, backpressure metrics, and connection lifecycle semantics unchanged.
- Verify with ten Rust lifecycle/backpressure tests, strict-zero quality, C-safe exports, and real connect/message/send/cancel smoke.
