# Release 0.2.26 / 发布 0.2.26

- Publish typed WebSocket FFI contract metadata for sync, blocking-callback,
  and async-stream boundaries.
- Upgrade the declared Calcit toolchain to 0.13.69.
- Runtime WebSocket ABI and behavior remain unchanged from 0.2.25.

- 发布同步、blocking-callback 与 async-stream WebSocket 边界的 typed FFI
  contract metadata。
- 将声明的 Calcit 工具链升级到 0.13.69。
- WebSocket runtime ABI 与行为相对 0.2.25 保持不变。
