# 发布 0.2.19 / Release 0.2.19

## 中文

- 发布基于稳定 `calcit_native_ffi 0.1.3` 的可取消 WebSocket server 事件背压。
- server 取消后不再向 host enqueue 普通业务事件，清理后的 terminal 仍可靠发布。

## English

- Release cancellable WebSocket server-event backpressure based on stable `calcit_native_ffi 0.1.3`.
- Stop enqueuing ordinary business events after server cancellation while reliably publishing the terminal event after cleanup.
