# 发布 0.2.20 / Release 0.2.20

- WebSocket server 任务现在返回类型化 `FfiTask`，并通过 `.cancel-with` 结束任务。
- 保持 `wss-each!` 的 `Unit` 契约，不为不可取消操作伪造 task capability。
- 使用 Calcit 0.13.59 完成类型检查和真实 connect/message/send/cancel 回归。

- WebSocket server tasks now return typed `FfiTask` values and terminate through `.cancel-with`.
- Preserved the `Unit` contract of `wss-each!` instead of inventing a task capability for a non-cancellable operation.
- Validated types and real connect/message/send/cancel behavior with Calcit 0.13.59.
