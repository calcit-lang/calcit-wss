# 发布 0.2.21 / Release 0.2.21

- 发布有界 per-connection outbound queue 与 `WssSendOutcome`。
- queue full 明确返回 backpressured，不在模块内丢弃或合并业务 patch。
- cancel/close 保持可用，slow socket write 有超时，cancel 最多 flush 一条已 accepted 的队首消息。

- Release bounded per-connection outbound queues and `WssSendOutcome`.
- A full queue explicitly returns backpressured without dropping or merging application patches.
- Cancel/close remains available, slow socket writes time out, and cancellation flushes at most one accepted head message.
