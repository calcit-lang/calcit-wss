# Release 0.2.23

- Bumped the Rust crate and Calcit module versions together from `0.2.22` to `0.2.23`.
- Publishes cancellation-aware socket close/read/write classification so post-cancel races remain `server-cancelled` instead of polluting failure metrics.
- Adds a real slow-reader, queue-full, and cancel-during-backlog regression while keeping the peer connected through server cleanup.
- Aligns the module toolchain with Calcit `0.13.61`.
