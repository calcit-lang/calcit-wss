# Release 0.2.25 / 发布 0.2.25

## 中文

- 发布 `calcit-wss` 0.2.25，包含可中断的非阻塞 WebSocket 握手与慢读端待写 frame 恢复。
- socket 返回 `WouldBlock`、`TimedOut` 或 `Interrupted` 时继续 flush tungstenite 已保留的 frame，不重复业务消息，也不误报 `write-failed`。
- 通过 12 项 Rust 测试、strict clippy、Calcit strict-zero quality、文档检查、真实 C-safe FFI smoke，以及 Calcium Workflow revision/ACK/resync 慢读端回归。

## English

- Release `calcit-wss` 0.2.25 with cancellable nonblocking WebSocket handshakes and pending-frame recovery for slow readers.
- When the socket returns `WouldBlock`, `TimedOut`, or `Interrupted`, continue flushing tungstenite's retained frame without duplicating business messages or reporting a false `write-failed` disconnect.
- Verify with 12 Rust tests, strict clippy, Calcit strict-zero quality, documentation checks, the real C-safe FFI smoke, and Calcium Workflow's revision/ACK/resync slow-reader regression.
